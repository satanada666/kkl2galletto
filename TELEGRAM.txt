━━━━━━━━━━━━━━━
❓ ПОЧЕМУ KKL НЕ РАБОТАЕТ С GALLETTO
1️⃣ Galletto ищет кабель по серийнику FTDI 47514789
2️⃣ Нужен PID 6001 (у китайских подделок бывает 0000)
3️⃣ Блок будится через DTR, а в KKL он никуда не подключён ➡️ errore data2 и нули

⚠️ Нужен KKL именно на FT232! CH340 не подойдёт ❌

━━━━━━━━━━━━━━━
🛠 ШАГ 1. FT_Prog (бесплатно с сайта FTDI)
🔌 KKL в USB, все программы закрыть
🔍 Devices → Scan and Parse
💾 File → Save Template As (бэкап!)
✏️ USB Device Descriptor → Product ID = 6001
✏️ USB String Descriptors:
   ▫️ Product Description = EOBD2
   ▫️ Auto Generate Serial ❌ снять
   ▫️ Serial Number = 47514789
⚡️ Program Devices → Program
🔄 Переткнуть USB
✅ В Galletto загорается «USB Device Active»

━━━━━━━━━━━━━━━
💡 ШАГ 2. Диод — программно! 😎
Galletto дёргает DTR через FTD2XX.dll из своей папки.
В этой DLL меняем 4 байта в таблице функций:
🔁 FT_SetDtr ➡️ FT_SetBreakOn
🔁 FT_ClrDtr ➡️ FT_SetBreakOff
Break сам прижимает TXD (K-линию) к нулю, то есть делает работу диода 🎯
Системный драйвер не трогаем, VCDS и другие программы работают как раньше 👍

🔩 Кто любит паяльник: 1N4148 на FT232RL
   ▫️ pin 1 TXD ← анод (без полоски)
   ▫️ pin 2 DTR ← катод (с полоской)
   ⚠️ Либо диод, либо патч DLL, не оба сразу!

━━━━━━━━━━━━━━━
🔌 СТОЛ, Vito 0281010436
➕ T1-1, T1-7 = +12 В
➖ T1-5 = масса
🔑 T2-13 = +12 через тумблер (зажигание)
📡 T3-28 = K-line
🔌 На OBD кабеля: 16 = +12 ❗️, 4/5 = масса, 7 = K-line
🚫 Резистор boot на Flash снять!

━━━━━━━━━━━━━━━
📖 ЧТЕНИЕ
👉 MERCEDES → BOSCH EDC 15 C5 E2 29F400BT → Vito 2.2 CDI
👉 ECU Data → 61 11 53 00 79 ✅
👉 FLASH + COMPLETE → Read ECU
📝 Путь файла вписывать вручную, например D:\VITO\1
   ⚠️ Если листать папки в окне сохранения, Win10 виснет и программа падает!
🔑 Зажигание выкл/вкл → OK
⏳ Окно «не отвечает», это нормально, ждём ~90 сек
💾 Файл 524 288 байт, читаем 2 раза и сравниваем хэши
